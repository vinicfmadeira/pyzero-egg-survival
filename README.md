# Egg Survival

Egg Survival é um jogo de ação e sobrevivência 2D desenvolvido com a biblioteca Pygame Zero. No jogo, você controla um ovo que deve lutar para sobreviver contra ondas de inimigos perigosos. Utilize suas habilidades de movimento e disparo para derrotar os garfinhos ameaçadores e alcançar a maior pontuação possível!

## Funcionalidades Atuais

* Menu principal interativo com botões para iniciar o jogo, controlar a música e sair.
* Música de fundo e efeitos sonoros para imersão.
* Controle do jogador com movimento em todas as direções (W, A, S, D).
* Mecânica de disparo em quatro direções (setas do teclado).
* Animação de sprite para o jogador durante o movimento e quando parado, com flip horizontal.
* Inimigos básicos que perseguem o jogador.
* Sistema de pontuação.
* Tela de Game Over.
* Criação contínua de ondas de inimigos.

## Como Jogar

1.  Clone este repositório para sua máquina local.
2.  Certifique-se de ter o Pygame Zero instalado (`pip install pgzero`).
3.  Execute o arquivo principal do jogo.
4.  No menu principal, clique em "PLAY" para iniciar o jogo.
5.  Use as teclas **W, A, S, D** para mover o ovo.
6.  Use as **setas do teclado (↑, ↓, ←, →)** para atirar gemas nos inimigos.
7.  Sobreviva o máximo de tempo possível e alcance a maior pontuação!
